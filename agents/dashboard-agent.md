# Dashboard Agent

## Descrição
Especialista em React, Next.js, Supabase Auth e Realtime.

## Responsabilidades
- Desenvolver páginas do dashboard (Next.js)
- Gerenciar autenticação via Supabase Auth
- Implementar subscriptions Realtime
- Criar componentes reutilizáveis
- Integrar com APIs Supabase

## Pages
| Rota | Descrição |
|---|---|
| `/` | Overview com métricas |
| `/conversations` | Histórico de conversas |
| `/contacts` | Perfil de contatos |
| `/appointments` | Gestão de agendamentos |
| `/reports` | Relatórios e exportação |

## Comandos úteis
```bash
cd src/dashboard && npm run dev
```
